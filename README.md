# AI ผู้ช่วยจัดการระบบสารสนเทศนักเรียน

**Student Information System Assistant** — ผู้ช่วย AI สำหรับประมวลผล วิเคราะห์ ค้นหา และสรุปข้อมูลนักเรียนโรงเรียนสามัคคีศรีวิชัย (รหัสโรงเรียน 51020099) จากฐานข้อมูลปีการศึกษา 2569

## ✨ สิ่งที่ระบบทำได้

- **แชทสำหรับสนทนาข้อมูลด้วยภาษาไทย:** ค้นหา/วิเคราะห์ข้อมูลด้วยคำสั่งภาษาที่เข้าใจง่าย
- **การค้นหารายบุคคล:** ด้วยเลขประจำตัวประชาชน, เลขประจำตัวนักเรียน, ชื่อ หรือนามสกุล
- **การกรองตามชั้น/ห้อง:** สรุปรายชื่อนักเรียนตามระดับชั้น/ห้อง พร้อมข้อมูลผู้ปกครอง
- **สรุปสถิติ:** จำนวนนักเรียนแยกเพศ/ระดับชั้น
- **งานดูแลช่วยเหลือนักเรียน:** กรองกลุ่มความด้อยโอกาส (เด็กยากจน/ยากจนพิเศษ)
- **วิเคราะห์ BMI:** คำนวณดัชนีมวลกายจากน้ำหนัก/ส่วนสูง เพื่องานอนามัยโรงเรียน
- **PDPA Masking:** ซ่อนเลกประจำตัวประชาชน/ที่อยู่เต็มเห็นเฉพาะเมื่อเปิด **โหมดครูประจำชั้น**
- **Import/Export CSV:** อัปโหลดไฟล์ `2569-1-student.csv` จริง และส่งออกผลการค้นหาเป็น CSV (UTF-8 BOM)
- **LocalStorage Persistence:** ข้อมูลไม่หายเมื่อรีเฟรชหน้าจอ

## 🔐 นโยบายคุ้มครองข้อมูล (PDPA)

- เลขประจำตัวประชาชน 13 หลักที่แสดงโดยพื้นฐานจะถูกมาสก์เป็นรูปแบบ `X-XXXX-XXXXX-XX-X`
- เปิด **"โหมดครูประจำชั้น"** เพื่อดูเลขประจำตัวประชาชนเต็มและที่อยู่เต็มสำหรับงานดูแลช่วยเหลือนักเรียนเซศเท่านั้น
- ข้อมูลที่เป็น `-` หรือ `0` จะแสดงเป็น "ไม่มีข้อมูลในระบบ" เสมอ

## 🛠 Tech Stack

- React 18 + Vite
- Tailwind CSS v4
- Lucide React
